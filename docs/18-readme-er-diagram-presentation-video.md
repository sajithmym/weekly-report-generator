## Optional handover assets

No ER diagram image, presentation deck, demo video, deployed public URL, shared-drive item, or final repository/share URL is stored in this project. Create any needed handover assets from the implemented behavior, never from an older plan.

The ER diagram should include User, Project, UserProject, Report, ReportTask, NextWeekTask, Blocker, Achievement, WorkHour, ReportVersion, Review, and RefreshToken. The demo should show member creation/submission, manager correction, member resubmission, manager approval, administrator user management, and dashboard/roster. Do not expose local passwords, JWTs, cookies, or connection strings.

Verify sharing permissions and required links before handing the project over.
